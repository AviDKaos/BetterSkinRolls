# Changelog

## 1.0.0

- Slot machine rolls skip the weapons (and the boat) whose obtainable skins you have all collected.
- With the host running the mod, the whole lobby sees the same filtered wheel, even players without it.
- Local fallback when the host doesn't have the mod (only your screen shows the changed roll).
- Completed weapons are struck through in the machine's "Prizes:" list.
- Settings: Enabled, Local fallback, Strike completed prizes, and the host's Lobby filter.
