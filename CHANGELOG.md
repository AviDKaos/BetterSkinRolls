# Changelog

## 1.0.0

- Slot machine rolls skip the weapons (and the boat) whose obtainable skins you have all collected.
- With the host running the mod, the whole lobby sees the same filtered wheel, even players without it.
- When the host doesn't have the mod, only your screen shows the changed roll.
- Completed weapons are crossed out in the machine's "Prizes:" list.
- Settings in game: a "Skin Rolls" tab in Options, each option with a short description. All texts in the game's 16 languages.
